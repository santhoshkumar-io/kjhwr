# Makes Python verify TLS against the operating system's trust store instead of
# OpenSSL's own bundle at /etc/ssl/cert.pem.
#
# Needed only on this network, which runs a TLS-inspecting proxy (Netskope). Its
# root CA is in the macOS keychain, so curl and the system Python 3.9 trust it,
# but the uv-managed CPython 3.12 reads /etc/ssl/cert.pem, which does not contain
# it - so every HTTPS call failed with CERTIFICATE_VERIFY_FAILED.
#
# Dev-only: it is used by the two fetch scripts, which never run in production,
# and both import it inside try/except ImportError so they work without it.
